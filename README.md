# Python Fundamentals Capstone
Hands-on project completed as part of the SkilloVilla Data Analytics & Generative AI course.
## What it covers
- Building DataFrames from dictionaries and saving/reading CSVs
- Handling missing values with a running average (NumPy)
- Splitting columns, merging multiple DataFrames
- Conditional logic with `np.where` and custom functions (bonus, demotion, promotion rules)
- Grouping and aggregating (`groupby`) and filtering with string methods
## Tools
Python, pandas, NumPy, Jupyter Notebook
## Files
- `Capstone project Python Fundamentals TJ.ipynb` – main notebook
- `*_DataFrame.csv` – input datasets
- `Task_Description.pdf` – problem statement
